# Bitcoin Trading System (BTS)

## Overview

Bitcoin Trading System (BTS) is a Python-based automated execution engine for
Bitcoin futures trading.

The system receives trading signals from an external machine learning model,
validates them, applies internal risk management, determines order quantity,
and executes trades through CQG.
